\section{Autómata de Reconocimiento de Comentarios Multilínea}

El siguiente autómata finito determinista (DFA) reconoce comentarios de estilo C delimitados por \texttt{/*} y \texttt{*/}, garantizando que finalice en la primera ocurrencia de \texttt{*/}:

\begin{figure}[htbp]
\centering
\begin{tikzpicture}[
    shorten >=1pt,
    node distance=2.5cm,
    on grid,
    auto,
    every state/.style={thick, fill=gray!10},
    initial text=
]
    % Estados
    \node[state, initial]           (q0) {$q_0$};
    \node[state]           [right=of q0] (q1) {$q_1$};
    \node[state]           [right=of q1] (q2) {$q_2$};
    \node[state]           [right=of q2] (q3) {$q_3$};
    \node[state, accepting][right=of q3] (q4) {$q_4$};

    % Transiciones
    \path[->, >=Stealth, thick]
        (q0) edge node[above] {\texttt{/}} (q1)
        (q1) edge node[above] {\texttt{*}} (q2)
        (q2) edge [loop above] node {\texttt{[\textasciicircum *]}} (q2)
        (q2) edge [bend left=25] node[above] {\texttt{*}} (q3)
        (q3) edge [loop above] node {\texttt{*}} (q3)
        (q3) edge [bend left=25] node[below] {\texttt{[\textasciicircum */]}} (q2)
        (q3) edge node[above] {\texttt{/}} (q4);

\end{tikzpicture}
\caption{DFA para comentarios multilínea (equivalente a \texttt{"/*"([\textasciicircum *]|*+[\textasciicircum */])* *+"/"}).}
\label{fig:automata_comentarios}
\end{figure}

\subsection{Descripción de Estados}
\begin{itemize}
    \item \textbf{$q_0$ (Inicial)}: Estado de partida antes de detectar la barra de apertura.
    \item \textbf{$q_1$}: Se leyó la barra inicial (\texttt{/}). Espera el asterisco de apertura.
    \item \textbf{$q_2$}: Dentro del cuerpo del comentario. Consume cualquier carácter que no sea asterisco (\texttt{[\textasciicircum *]}).
    \item \textbf{$q_3$}: Se detectó uno o más asteriscos (\texttt{*}). Si el siguiente carácter es barra (\texttt{/}), transiciona a $q_4$ cerrando el comentario; si es otro carácter, regresa a $q_2$.
    \item \textbf{$q_4$ (Aceptación)}: Comentario cerrado con éxito.
\end{itemize}
