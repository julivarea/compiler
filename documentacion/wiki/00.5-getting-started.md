# Primeros Pasos

Esta página proporciona la configuración básica para compilar y ejecutar el compilador.

## Prerrequisitos
- GCC
- Flex y Bison

## Instalación y Construcción
Genera el parser y el scanner en `build/` y compila todo en `./mi_compilador`.
Hay que volver a correrlo tras cada cambio en `src/`.

```bash
./build.sh
```

## Tests
Regenera Flex/Bison y corre los tests unitarios (Unity) de lexer y parser.
Compila su propia copia de los fuentes, así que no valida el ejecutable que
dejó `build.sh`.

```bash
./test_suite.sh
```

## Ejecución del Compilador
Corre las cuatro fases (léxico, sintáctico, AST, semántico) e imprime el árbol
si no hubo errores. Sin argumento lee de la entrada estándar.

```bash
./mi_compilador examples/programa.txt
```

## Puntos de Entrada
- `src/bison.y` — Contiene la función `main()` y dirige el proceso de parseo.
- `src/lexer.l` — Contiene las reglas léxicas.
- `src/symbol_table.c` — `analyzeSemantics`, el recorrido del análisis semántico.

El detalle de qué imprime cada fase, los códigos de salida y los problemas
conocidos están en el [Inicio](../index.md).
