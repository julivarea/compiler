# Primeros Pasos

Guía rápida para compilar, probar y ejecutar el compilador.

---

## Prerrequisitos

- **GCC** (con soporte para C99 o superior)
- **Flex** (versión 2.6 o superior)
- **Bison** (versión 3.x)

---

## Compilación

Compila el parser, scanner y todos los módulos del compilador, generando el ejecutable `./mi_compilador`:

```bash
bash build.sh
```

---

## Ejecución de Pruebas

Ejecuta la suite de pruebas unitarias automatizadas sobre el analizador léxico y el analizador sintáctico:

```bash
bash test_suite.sh
```

---

## Ejecución del Compilador

Para compilar un programa de ejemplo en C-TDS:

```bash
./mi_compilador examples/programa.txt
```

También es posible enviar código a través de la entrada estándar (*stdin*):

```bash
echo "void main() { int x; }" | ./mi_compilador
```
